# 回合制战棋地图系统 - 快速参考卡片

## 🎯 核心概念

### 架构（推荐方案）
```
MapRoot (Node2D)
├── TileMapLayer0      # 基础地形 (Z=0)
├── TileMapLayer1      # 建筑装饰 (Z=1)
├── UnitsContainer     # 棋子容器 (Z=2)
└── HighlightLayer     # 高亮层 (Z=10)
```

### 数据存储（稀疏 Dictionary）
```gdscript
# ✅ 推荐：只存有内容的格子
var map_data = {
	Vector2i(0, 0): 1,  # 陆地
	Vector2i(1, 0): 2,  # 河流
	# 虚空格子不存储
}

# ❌ 不推荐：满数组（浪费内存）
var map_array = [[1,1,1,...], [1,2,1,...], ...]
```

## 📦 核心类速查

| 类名 | 用途 | 关键方法 |
|------|------|----------|
| **MapData** | 数据存储 | `set_terrain()`, `get_move_cost()`, `save_to_file()` |
| **MapGenerator** | 地图生成 | `generate_full_map()`, `inject_template()` |
| **MapLoader** | 场景加载 | `load_map()`, `generate_and_load_map()` |
| **MovementRangeCalculator** | 移动计算 | `calculate_movement_range()`, `calculate_path()` |
| **MapRoot** | 总控制器 | `add_unit()`, `generate_new_map()` |

## 🚀 常用代码片段

### 1. 生成地图
```gdscript
var generator = MapGenerator.new(50, 50, 12345)
var map_data = generator.generate_full_map(2, 3)  # 平滑2次，3个村庄
```

### 2. 加载地图
```gdscript
var loader = MapLoader.new()
loader.layer0 = $TileMapLayer0
loader.layer1 = $TileMapLayer1
loader.load_map(map_data)
```

### 3. 计算移动范围
```gdscript
var calculator = MovementRangeCalculator.new(map_data)
var reachable = calculator.calculate_movement_range(
	Vector2i(10, 10),  # 起点
	5,                 # 移动力
	occupied_cells     # 障碍物
)
```

### 4. 显示高亮
```gdscript
highlight_layer.show_movement_range(reachable)
highlight_layer.show_path(path)
highlight_layer.clear_highlights()
```

### 5. 移动棋子（带动画）
```gdscript
var tween = create_tween()
for cell in path:
	var pos = layer.map_to_local(cell)
	tween.tween_property(unit, "position", pos, 0.2)
```

### 6. 保存/加载
```gdscript
# 保存
map_data.save_to_file("user://my_map.json")

# 加载
var loaded = MapData.load_from_file("user://my_map.json")
```

## ⚙️ 配置速查

### 地形类型
```gdscript
enum TerrainType {
	VOID = 0,      # 虚空（不存储）
	LAND = 1,      # 陆地 成本=1.0
	RIVER = 2,     # 河流 成本=2.0
	MOUNTAIN = 3,  # 山地 成本=INF
	FOREST = 4,    # 森林 成本=1.5
	VILLAGE = 5    # 村庄 成本=1.0
}
```

### 修改地形成本
```gdscript
# 在 MapData.gd 中
const TERRAIN_COSTS = {
	TerrainType.LAND: 1.0,
	TerrainType.RIVER: 2.0,    # 改成 3.0 让河流更难通过
	TerrainType.FOREST: 1.5
}
```

### 修改生成参数
```gdscript
# 在 MapGenerator.gd 中
noise.frequency = 0.05      # 越小地形越平滑
noise.noise_type = FastNoiseLite.TYPE_PERLIN  # 噪声类型
```

## 🎨 TileSet 配置要点

### 必须配置
1. **Terrain Sets**（自动边缘连接）
   - Terrain Set 0: 陆地系统
   - Terrain Set 1: 河流系统

2. **Custom Data Layers**（移动成本）
   - `move_cost` (Float): 1.0 / 2.0 / INF
   - `block_movement` (Bool): true / false

3. **Atlas 坐标映射**
```gdscript
# 在 MapLoader.gd 中更新
const TERRAIN_TO_ATLAS = {
	MapData.TerrainType.LAND: Vector2i(0, 0),
	MapData.TerrainType.RIVER: Vector2i(1, 0),
	# ... 根据你的 TileSet 配置
}
```

## 🐛 常见问题 1 秒解决

| 问题 | 解决方案 |
|------|----------|
| 地图不显示 | 检查 TileMapLayer 是否设置了 TileSet |
| 边缘不连接 | 配置 Terrain Sets + 调用 `update_internals()` |
| 移动范围错误 | 检查 `TERRAIN_COSTS` 配置 |
| 棋子卡顿 | 不要把棋子放进 TileMapLayer，用独立 Node2D |
| 文件太大 | 使用 Dictionary 稀疏存储，不存虚空格子 |

## 📝 关键注意事项

### ✅ 推荐做法
- 使用 Dictionary 稀疏存储
- 使用 Terrain Sets 自动连接
- 使用 AStarGrid2D 计算路径
- 棋子用独立 Node2D + Tween 动画
- 调用 `layer.update_internals()` 更新地形

### ❌ 禁止做法
- 不要用满 2D 数组存储地图
- 不要把棋子放进 TileMapLayer
- 不要手动处理地形边缘连接
- 不要存储虚空格子（浪费内存）
- 不要忘记调用 `update_internals()`

## 🔧 扩展模板

### 添加新地形
```gdscript
# 1. MapData.gd - 添加枚举
enum TerrainType {
	# ...
	DESERT = 6  # 新增：沙漠
}

# 2. MapData.gd - 配置成本
const TERRAIN_COSTS = {
	# ...
	TerrainType.DESERT: 2.5
}

# 3. MapGenerator.gd - 添加映射
func _noise_to_terrain(noise_value: float) -> int:
	if noise_value > 0.7:
		return MapData.TerrainType.DESERT

# 4. MapLoader.gd - 配置坐标
const TERRAIN_TO_ATLAS = {
	# ...
	MapData.TerrainType.DESERT: Vector2i(5, 0)
}
```

### 自定义生成算法
```gdscript
class_name MyGenerator extends MapGenerator

func generate_basic_map() -> MapData:
	var map_data = MapData.new(width, height)
	
	# 你的自定义逻辑
	for x in range(width):
		for y in range(height):
			# 例如：棋盘格图案
			var terrain = MapData.TerrainType.LAND if (x + y) % 2 == 0 else MapData.TerrainType.FOREST
			map_data.set_terrain(Vector2i(x, y), terrain)
	
	return map_data
```

## 💡 最佳实践

### 地图生成
```gdscript
# ✅ 好：使用种子，可重现
var gen = MapGenerator.new(50, 50, 12345)

# ✅ 好：后处理优化
var map = gen.generate_full_map(2, 3)  # 平滑+村庄

# ❌ 差：不平滑，地形混乱

```

### 移动计算
```gdscript
# ✅ 好：考虑障碍物
var range = calc.calculate_movement_range(pos, 5, occupied)

# ❌ 差：忽略障碍物，棋子重叠
var range = calc.calculate_movement_range(pos, 5, [])
```

### 棋子管理
```gdscript
# ✅ 好：通过 MapRoot 管理
map_root.add_unit(unit, cell)

# ❌ 差：直接添加，无法追踪
units_container.add_child(unit)
```
